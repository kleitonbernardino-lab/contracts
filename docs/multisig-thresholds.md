# Weighted Multi-Signature Threshold Specification

## Consensus Thresholds
- **Low Threshold (1/N):** Non-critical operational status inquiries and heartbeat reports.
- **Medium Threshold (M/N, typically 2/3):** Standard payout authorizations and parameter adjustments.
- **High Threshold (N/N or Supermajority):** Contract code hash migration, emergency pause, and key rotation.
